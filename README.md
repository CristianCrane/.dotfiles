# dotfiles

The NixOS-on-WSL system (`flake.nix`, `configuration.nix`, `home.nix`) and Claude Code's own config (`home/.claude`), applied with `rebuild`; `CLAUDE.md` says how to work here.

**Moving machines:** copy `~/.claude/process` and `~/.claude/projects` across too. They're local only, with no backup: the process layer's inbox and the sessions' memory (`docs/process.md`, The inbox).
